## 一段话说清 SAiCoN

SAiCoN 是一条 Layer-1 区块链，验证者获得报酬是因为他们**做了什么**，而不是因为他们**持有什么**。
每个纪元，网络都会度量每一个验证者的参与——它签署了哪些区块、轮到它出块时表现如何——并且只向那些
活跃、合规且确实参与了的验证者付款。质押仍然决定谁能进入，也仍然为奖励加权，但它不决定谁被选中。
决定这件事的是声誉。原生代币 SCN 的供应量固定为 2100 万，由代码在每一次铸造之前强制校验。

## 问题在哪

在普通的权益证明里，资本会自我复利。最大的质押赚得最多，于是买得更多，最终十个运营者之间就控制了
网络的三分之一。而在这样的网络上，**把验证者运行好**和**只是运行着**，报酬完全一样。

## 想法

把质押承担的两件事分开。**质押让你获得准入**——2,000 SCN 的自质押，锁定 60 天，
这样每一个节点背后都站着一个有真实风险敞口的真实运营者。一旦被选中，**质押为你的奖励加权**。
但**决定你是否被选中的是参与**，而参与是从区块链自身度量出来的：签名与出块轮次，每个节点都能核验。

## 一个验证者如何获得收益

1. **注册**，附带 2,000 SCN 自质押。它被锁定 60 天。日后离开还需经过网络 21 天的解绑期，
   且无法缩短。

2. **参与。** 每个纪元都会依据在线率与出块质量产出一个参与度评分。

3. **积累声誉。** 该评分被平滑为一个跌得快、恢复得慢的声誉值。在一次三天的宕机之后，
   需要十个纪元的完美参与才能重新具备资格。声誉易失难得——这是刻意为之。

4. **被选中。** 活跃集设计为 75 个席位，最终规模由一次共识基准测试确定。七成给予声誉最高者；
   三成在其余者中通过可验证的抽签产生，每个经核实的运营者一张票。质押在排名中不起任何作用。

5. **获得收益。** 该纪元的奖励在通过关卡的被选中验证者之间分配，按投票权重成比例——
   即封顶后的质押量乘以声誉。

## 是什么让它保持去中心化

是限制，不是折扣。

- 任何验证者持有的质押都不超过已质押总量的 **2%**。
- 任何现实世界中的运营者持有的都不超过 **5%**、不超过**两个席位**、不超过**一张抽签票**——
  无论它运行多少个节点。
- 超过全局上限之后，新的质押会**在队列中等待**。
- 一个委托人最多分散到三个验证者，而溢出会被引离集中之处，流向有余量、记录良好的较小验证者。

在仿真中，仅仅是两个席位的限制，就把一个建模攻击者的最大投票权重从 53.8% 压到了 3.2%。

合规是一道关卡，而不是一项评分——没通过就出局，无论你在别处表现如何。能源来源会被记录并公开，
但不携带任何经济权重：每一个为此付费的版本都被证明会诱使人们**为证书付费，而不是为能源付费**。

## SCN 代币

| | |
|---|---|
| 供应上限 | **21,000,000 SCN**——代码中的一个常量，每次铸造前都会校验 |
| 谁能铸造 | 恰好一个模块；标准的通胀模块不在本应用中 |
| 发行 | 一份安全预算：每年已质押量的 15%，并限制在供应量的 0.5–0.75% 之间——按当前网络快照约为每天 238 SCN |
| 交易手续费 | 在计入奖励之前先减少新增发行；当年手续费约达 100,000 SCN 时，铸造停止 |
| 精度 | 8 位小数；基本单位 `nscn` |

项目社区目前在 Base 网络上持有一种更早的代币。主网之后，它的余额将依据一条在 genesis 之前公布的规则
转换为 SCN 质押。

## 安全

- **双签**的代价是 10% 的质押，以及对该密钥的永久封禁。
- **普通宕机**的代价是声誉与奖励，而不是质押——硬件故障不该被当作欺诈对待。
- **卡特尔**首先由证明机制应对——每个验证者在能被选中之前都要关联到一个经核实的运营者——
  其次由一个检测器应对，而它只能隔离，绝不能独自罚没。
- **运行时不变式**会让链停下，而不是任由它的账目悄悄发散。
- 治理是**有边界的**：任何投票都不能抬高供应上限、增加铸造路径、降低锁定期、
  推翻罚没或解除封禁。

## 目前进展

**已经在公开的开发者网络上运行：** 四个协议模块、质押限制与委托路由器、完整的验证者生命周期、
参与度关卡、唯一铸造路径与供应上限、发行预算、运行时不变式，以及一个公开的区块浏览器、计分板与接口。

**接下来：** 实体注册表、基于参与度的投票权重、公开测试网、共识基准测试与外部审计。
真实发放跟在审计之后，而不是之前。

**数字背后：** 一整套已执行的仿真计划——十九项研究，每一项都说明了它**没有**证明什么。
