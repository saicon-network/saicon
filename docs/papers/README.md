# Papers

- [`SAiCoN_WHITEPAPER.md`](SAiCoN_WHITEPAPER.md): the white paper, the full design of the Proof of
  Participation mechanism, the economics and the staged path to a production network.
- [`SAiCoN_LITEPAPER.md`](SAiCoN_LITEPAPER.md): the short version.

The two English files are the sources. A translation sits beside its source as
`<NAME>.<lang>.md`; the Chinese ones are `SAiCoN_WHITEPAPER.zh.md` and `SAiCoN_LITEPAPER.zh.md`.
Sections of a translation are matched to the English by position, so a translation keeps the
sections in the same order as its source. If you correct a figure in a paper, please say in the
pull request which sections of the translations need a second look.

For what the code does today, and where it still differs from the papers, read
[chain/docs/DEVELOPMENT.md](../../chain/docs/DEVELOPMENT.md).
